# SFX PRO — Landing Page & Portal do Cliente (Lovable / Web Deploy)

Este pacote contém todos os arquivos prontos para publicação na **Lovable**, **Vercel**, **Netlify** ou qualquer hospedagem web.

---

## 📁 Estrutura dos Arquivos

* `index.html` — Landing page de alta conversão, simulador interativo do AUTO SFX com Web Audio, Área do Cliente e Central de Administrador.
* `css/style.css` — Estilos visuais, layout responsivo para celular/desktop e temas escuros de alta fidelidade.
* `js/main.js` — Lógica do simulador com síntese de áudio, login unificado, gestão de licenças, link do checkout Kiwify e downloads.
* `assets/` — Ícones oficiais, logos em SVG e gráfico de onda sonora.
* `package.json` & `vite.config.js` — Permite que a Lovable execute o projeto como um app moderno com `npm run dev`.

---

## 🚀 Como Colocar no Ar Pela Lovable

1. **Acesse a Lovable ([lovable.dev](https://lovable.dev/)).**
2. Crie um novo projeto.
3. Se estiver usando sincronização com o **GitHub**:
   * Crie um repositório no seu GitHub (ex: `sfx-pro-web`).
   * Suba o conteúdo desta pasta para o repositório.
   * Conecte a Lovable ao repositório do GitHub.
4. Se estiver importando diretamente:
   * Arraste ou copie os arquivos desta pasta para o projeto da Lovable.
5. Clique em **Publish / Deploy** na Lovable para obter seu link público instantâneo com HTTPS!
